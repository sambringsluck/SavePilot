# Security policy

SavePilot is currently a developer preview. Please do not include private files, API keys, access tokens, or personal document contents in a public issue.

For a security or privacy report, use GitHub's private vulnerability reporting feature for this repository. Include the affected version, operating system, reproducible steps, and the least sensitive example possible.

Supported code is the latest commit on `main` and the latest tagged release. Older development builds may not receive fixes.

Public macOS binaries produced by GitHub Actions are ad-hoc signed for testing. A stable consumer release still requires Apple Developer ID signing and notarization; until then, macOS may display a Gatekeeper warning and Accessibility permission may need to be granted again after an update.
